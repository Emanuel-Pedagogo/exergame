🎮 Protótipos do Exergame

Lugar para experimentar visual e animação sem tocar no app. Cada página carrega o CSS real e sobrescreve só o que propõe mudar.

  • Referência — o visual de hoje Painel do aluno, responder questão, fim de lista e conquistas, sem nenhuma alteração. A régua para comparar as propostas.
  • Tema noturno Mesma estrutura, identidade escura. Mostra quanto dá para mudar só redefinindo os tokens de cor — e onde o app ainda tem cor fixa.
  • Bancada de animações Quatro receitas de comemoração (atual, discreta, festa, só a onda) para disparar e comparar no mesmo lugar.

Estes arquivos não entram no app.

Nada em src/ importa esta pasta, e o build só empacota o que parte de index.html da raiz. Quebrar um protótipo aqui não afeta o Exergame publicado.

Para criar o próximo, copie referencia.html e escreva no <style> apenas o que muda — esse bloco vira o patch quando a proposta for aprovada. Detalhes no README.md da pasta.
